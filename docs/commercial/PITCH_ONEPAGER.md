# ILearn Pitch One-Pager（软上线）

## 问题
K12 家庭与教师需要的不是「更快出答案」，而是**课标对齐、可审计、可行动**的学情闭环。

## 方案
ILearn：多 Agent 编排的诊断—规划引擎。  
**测评 → 批改 → 诊断 → 规划 → 巩固**，辅导走苏格拉底护栏，掌握度有证据，报告可带走。

## 初衷（不妥协）
课标在环 · 批改可审计 · 掌握度双轨 · 不泄终答 · 试点诚实（小学数学 4–6 · 北京·人教）

## 差异
相对搜题工具：卖证据与闭环。  
相对硬件巨头：轻部署、可审计、开源可验证。  
相对 Khanmigo：中国课标 citation + 批改收据。
