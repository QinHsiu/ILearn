# ILearn「集总竞品所长 · 单点能力全面超越」设计规格

**日期：** 2026-09-15  
**策略升级：** 从「一轮模仿一个竞品」升级为「按能力维度取各家最强标准，并在该单点上同时超过全部对照竞品」。  
**初衷不变：** 课标在环 · 批改可审计 · 掌握度双轨 · 辅导不泄终答 · 试点诚实（小学数学 4–6 · 北京·人教）

---

## 1. 原则

1. **集总所长：** 每个能力柱（Capability Pillar）先列出 12 家竞品在该点的「最佳实践水位」。  
2. **单点超越：** ILearn 在该柱上的验收标准必须 **严格高于** 该水位（可测量、可演示、可测试）。  
3. **禁止平均主义：** 不允许用「整体差不多」掩盖某一柱落后。  
4. **禁止异化初衷：** 超越搜题类时，不得靠「更快给终答」取胜；必须靠「更好的学习证据与引导」取胜。  
5. **一轮一柱：** 每次迭代只攻坚 **一个** 能力柱（可引用多家竞品作为水位，但交付只服务这一柱）。

---

## 2. 对照竞品集合（12）

松鼠 AI · 科大讯飞学习机 · 小猿 AI · 学而思/小精龙 · 作业帮 · 洋葱学园 · Khanmigo · Photomath · Gauth · 豆包爱学 · Century/Knewton 类 · OpenMAIC/DeepTutor

---

## 3. 十大能力柱与「全场碾压」定义

> 每个柱的 **Win Bar** = 超过该柱上所有竞品最佳实践的可验收标准。

### P1 · 课标可追溯（Curriculum Traceability）

| 竞品水位 | 代表 |
| --- | --- |
| 区域考情/教材同步 | 讯飞、作业帮 |
| 标准对齐叙述 | Khanmigo（内容库） |
| 开源可审计绑定 | OpenMAIC 类 |

**Win Bar（超越全部）：**  
每一道诊断/巩固题与计划日任务均可展开：**地区课标条目 ID + 教材章节 + 例题 source_ref + 引用置信度**；无 citation 的题不得进入正式卷（fail closed）。竞品多为「宣称同步」或「内容库绑定」，ILearn 要做到 **题级可点开溯源**。

### P2 · 掌握度严谨性（Mastery Rigor）

| 竞品水位 | 代表 |
| --- | --- |
| 掌握度北极星 | 小猿 |
| 知识点极细 + 实时路径 | 松鼠 |
| 诊–学–练–测闭环 | 小猿/学而思 |

**Win Bar：**  
practice / probe **双轨** + KnowledgeEvidence + leech/gap 显式暴露；「提示后做对」不得计为已掌握；对外报告同时展示 **掌握度、证据条数、probe 缺口**。超过小猿的「单一掌握度分」、超过松鼠的「黑盒细粒度」。

### P3 · 苏格拉底护栏（Socratic Guard）

| 竞品水位 | 代表 |
| --- | --- |
| 不给终答 | Khanmigo |
| 启发式答疑 | 讯飞 |
| 直接给步骤/答案（反面） | Photomath/Gauth/作业帮 |

**Win Bar：**  
状态机 + 多级 Guard + UI 伦理条 + soft-exit；**自动评测**：对含 `answer_key` 的 fixture，Tutor 全路径输出不得出现终答字符串；提示用尽强制复习出口。伦理与可测性同时超过 Khanmigo 的「产品叙述」。

### P4 · 分步可视且不泄题（Step Viz without Leak）

| 竞品水位 | 代表 |
| --- | --- |
| 分步极强 | Photomath |
| 可追问解释 | Gauth |

**Win Bar：**  
错题复盘展示 **完整 rubric 步骤图/列表 + 学生步骤对齐高亮**；终答默认遮罩；可选「家长/教师解锁终答」权限位。观感追上 Photomath，合规上全面反超。

### P5 · 批改可审计（Auditable Grading）

| 竞品水位 | 代表 |
| --- | --- |
| 自动批改率叙事 | 学而思/讯飞 |
| 黑盒 OCR 一体 | 多数作业 App |

**Win Bar：**  
OCR 与判分分离；每题 `GradingReceipt`（试卷版本、grader 版本、规则/LLM 路径、降级标记）可导出；家长/教师可「复核一条批改」。业界几乎无人公开收据 → 此柱易成绝对领先。

### P6 · 家长可行动性（Parent Actionability）

| 竞品水位 | 代表 |
| --- | --- |
| 家长指标看板 | 松鼠、讯飞 |
| 一分钟可读 | 头部学习机周报 |

**Win Bar：**  
一分钟摘要含：**进步 / 缺口 / 今晚 3 件可执行家务式任务**；每条任务绑定薄弱 KP；可一键生成「亲子口述题卡」PDF。超过「只有图表没有行动」。

### P7 · 教师决策闭环（Teacher Decision Loop）

| 竞品水位 | 代表 |
| --- | --- |
| 干预推荐 | Century |
| 班级诊断 | 学而思、讯飞 |

**Win Bar：**  
热力/分层 → **一键生成分层巩固卷（基础/提高/挑战）** → 布置回执；next_step 必须可点击执行，而非纯文案。超过 Century 的「建议」、学而思的「看板」。

### P8 · 低龄认知负荷（Cognitive Load）

| 竞品水位 | 代表 |
| --- | --- |
| 先概念再题 | 洋葱 |
| 单题聚焦 | 洋葱/学习机 |

**Win Bar：**  
移动端默认单题；概念微课入口在 hint 用尽后出现；测评计时 **排除系统动画**（公平计时）。体验细腻度对标洋葱，公平性超越硬件机。

### P9 · 入口与转化摩擦（Activation Friction）

| 竞品水位 | 代表 |
| --- | --- |
| 秒进辅导 | Gauth、豆包 |
| 搜题入口 | 作业帮 |

**Win Bar：**  
Landing → 三角色完整 Demo **≤2 次点击、≤60s 见核心证据**（掌握度或 citation 或收据之一）；深链可 resume。不以给答案换转化。

### P10 · 编排可观测与信任（Orchestration Trust）

| 竞品水位 | 代表 |
| --- | --- |
| 模块化 Agent | OpenMAIC/DeepTutor |
| 黑盒大模型套壳 | 多数 ToC |

**Win Bar：**  
对外 Trust 页 + `/capabilities` + 会话 `decision_log` 摘要 API + 阶段质量门状态可见；开源可复核。信任透明度超过闭源巨头与多数开源 Demo。

### P11（加分柱）· 长期陪伴连续性（Companion Continuity）

| 竞品水位 | 学而思小精龙、豆包爱学 |
| **Win Bar** | 跨会话学习者画像稳定、下一挑战连贯、挫败 replan 可解释；7 日连续任务链 |

### P12（加分柱）· 错题资产沉淀（Error Asset）

| 竞品水位 | 作业帮错题本 |
| **Win Bar** | 错题本含 citation + 证据 + 重练卷；导出 PDF；**仍不提供一键看终答** |

## 4. 现状基线（相对 Win Bar）

| 柱 | 现状粗评 | 距 Win Bar |
| --- | --- | --- |
| P1 课标 | 有 citation/source_refs，未做到「无 citation fail closed」全链路 | 中 |
| P2 掌握度 | 双轨与证据已有，对外暴露不足 | 中 |
| P3 护栏 | Tutor soft-exit + 伦理 UI 已有，缺自动泄漏评测门禁 | 中低 |
| P4 分步 | StepReviewList 初版，缺步骤对齐高亮 | 中 |
| P5 收据 | 后端有模型，导出/UI 复核弱 | 高 |
| P6 家长 | 一分钟摘要已有 | 中低 |
| P7 教师 | next_step 文案有，缺一键分层出卷 | 高 |
| P8 低龄 | 移动单列 + 计时公平有基础 | 中 |
| P9 入口 | Demo/候补有 | 低 |
| P10 信任 | Trust 页有，decision_log 对外不足 | 中 |
| P11 陪伴 | demo resume 有，长期链弱 | 高 |
| P12 错题 | 部分有，资产化不足 | 中高 |

## 5. 迭代波次（详细执行见 plan）

- **Wave A（夯实碾压基座）：** P3 → P2 → P1 → P5  
- **Wave B（角色闭环碾压）：** P6 → P7 → P12  
- **Wave C（体验与信任碾压）：** P4 → P8 → P9 → P10  
- **Wave D（长期护城河）：** P11 + 公开基准评测套件

每波内 **严格一轮一柱**；柱完成须附带：**竞品水位表更新 + 自动测试 + 人工 5 分钟演示脚本**。
