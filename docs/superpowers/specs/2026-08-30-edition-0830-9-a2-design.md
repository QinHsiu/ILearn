## Goal

Close remaining 0830_9 product gaps without redoing PhaseGuard / locks / LLM fallback / FeatureRegistry / multi-round revise:

1. **E-004** region-not-supported friendly error + mapping
2. Extend **SubjectAdapter** with `get_supported_regions` and soft `get_curriculum` (unsupported payload, not throw)
3. **Session sync:** `GET /sessions/{id}`, minimal `POST .../heartbeat`, frontend `useSessionSync` wired into `StudentApp`

## Architecture (approved §1)

Thin enhancements on existing modules; frontend sync without new global store.

| Component | Path | Responsibility |
| --- | --- | --- |
| Subject adapter | `ilearn/core/subject_adapter.py` | `get_supported_regions()`, `get_curriculum(grade, region) -> dict` |
| Errors | `ilearn/core/user_errors.py` | Register **E-004**; map region messages |
| Region gate | `ilearn/api/app.py` and/or small helper | Reject create (or assess) when region not in supported set → E-004 |
| Session GET | `ilearn/api/app.py` | `GET /sessions/{session_id}` → `SessionState` |
| Heartbeat | `ilearn/api/app.py` | `POST /sessions/{session_id}/heartbeat` → `{ok, phase, server_time}` |
| Client | `frontend/src/api/client.ts` | `getSession`, `heartbeat` |
| Sync hook | `frontend/src/hooks/useSessionSync.ts` | visibility refetch + 30s heartbeat + beforeunload |
| Wire-up | `frontend/src/App.tsx` (`StudentApp`) | Apply synced state like resume |

### SubjectAdapter extensions

Keep existing: `get_grade_range() -> (4, 6)`, `supports(grade)`, `curriculum()`, `get_adapter("math", ...)`.

Add:

- `get_supported_regions(self) -> list[str]` — Math: `["北京", "上海"]` (canonical Chinese labels).
- `get_curriculum(self, grade: int, region: str) -> dict`:
  - If `not supports(grade)`: `{ "status": "unsupported", "message": "<friendly Chinese>" }`
  - If region not in supported (after alias normalize): `{ "status": "unsupported", "message": "..." }` suitable for E-004 messaging
  - Else: `{ "status": "ok", "label": curriculum.label, "grade": grade, "region": canonical }`

Region alias normalize (shared helper): `北京`/`beijing` → `北京`; `上海`/`shanghai` → `上海`; else unknown.

**Do not** change `require_pilot_grade` behavior on paper generation.

### E-004

```text
E-004 user_action: 当前地区课标数据暂未覆盖，请切换至北京或上海地区。
technical_prefix: RegionNotSupported / region
```

Raise `UserFriendlyError("E-004", ...)` when creating a session with unsupported region (after alias normalize). Shanghai allowed. Existing non-Beijing disclaimer in diagnosis can remain for nuance; E-004 is for **unknown** regions only.

### Session sync API

- `GET /sessions/{session_id}` → load via store; 404 if missing; response_model `SessionState`.
- `POST /sessions/{session_id}/heartbeat` → load session; optionally set `metadata["last_heartbeat"]` ISO timestamp and save; return `{ "ok": true, "phase": <phase value>, "server_time": <iso> }`.

### Frontend `useSessionSync`

Props: `sessionId: string | null`, `onSync: (state: SessionState) => void`, `hasUnsavedChanges: () => boolean`.

Behavior:

1. No-op when `sessionId` null.
2. On `visibilitychange` → visible: `api.getSession` → `onSync`.
3. Interval 30s: `api.heartbeat(sessionId)`; failures set internal `isSynced=false`.
4. `beforeunload` if `hasUnsavedChanges()`.

`StudentApp.onSync`: update `paper`, `answers` from session, adjust `step` similarly to `onResume` (without requiring report); optionally refresh report in background later — MVP: sync core fields only.

## Data flow / errors / tests (approved §2)

### Data flow

1. Profile submit → region normalize → unsupported → E-004; else create.
2. Soft curriculum probe (tests / optional UI later) via adapter `get_curriculum`.
3. Active student session → sync hook → GET on focus / heartbeat keepalive.

### Error handling

| Case | Behavior |
| --- | --- |
| Unknown region on create | E-004 |
| Grade outside 4–6 on assemble | E-001 (unchanged) |
| Missing session GET/heartbeat | 404 |
| Heartbeat network fail | hook marks unsynced; do not clear local answers |
