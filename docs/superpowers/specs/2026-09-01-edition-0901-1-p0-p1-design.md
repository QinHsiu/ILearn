# Edition 0901_1 Design — Structured Summaries + Role Picker + ComparisonCards (P0 + P1)

**Date:** 2026-09-01  
**Status:** Ready for user review (self-reviewed)  
**Source:** `doc/edition_0901_1.txt` (P0 + P1 only)  
**Baseline:** Edition 0901 (PR #19) — pre-seeded `math_5_1` demo + effectiveness stack  
**Approach:** 方案 1 — extend existing modules (no dashboard rewrite, no react-router)

## Goal

Close the judge-facing gaps left after 0901: structured teacher/parent summaries, Landing role picker before demo jump, student deep-link resume into the same demo session, and before/after ComparisonCards on the effectiveness UI.

## Scope

**In (P0 + P1):**

1. Extend `ilearn/core/audience_summary.py` with Pydantic `TeacherSummary` / `ParentSummary` + builders from session (+ `demo_class_data`)
2. `GET /sessions/{id}/summary/teacher` and `GET /sessions/{id}/summary/parent`
3. Landing: role toggle (teacher / parent / student) → `createDemoSession` → navigate to `links[role]`
4. Student deep link: use existing seed shape `?student=1&session_id=<sid>`; `StudentApp` mounts with `onResume(session_id)`
5. Effectiveness UI: ComparisonCards (mastery before/after, weaknesses, grading time, confidence + evidence)
6. Seed: set `metadata.post_assessment_score = clamp(pre + demo_mastery_gain, 0, 100)` so metrics expose real before/after

**Out (this round):**

- Dedicated StudentDashboard page
- Parent message / 预约 stubs
- Class-report PDF
- react-router migration
- Async SessionService rewrite
- New demo units beyond `math_5_1`

## Architecture (approved §1)

| Layer | Path | Responsibility |
| --- | --- | --- |
| Structured summary | `ilearn/core/audience_summary.py` | Keep string `generate_audience_summary`; add models + `build_teacher_summary(session)` / `build_parent_summary(session)` |
| Metrics reuse | `ilearn/core/effectiveness.py` | Unchanged API; summaries may call `compute_metrics` for rates / time saved |
| Seed | `ilearn/demo/seed.py` | Write `post_assessment_score` from pre + `demo_mastery_gain` |
| Demo links | `ilearn/api/demo.py` | Already returns `links.student` with `session_id`; no shape change required |
| API | `ilearn/api/app.py` (or thin router) | Two GET summary endpoints |
| Landing | `frontend/src/pages/LandingPage.tsx` | Role toggle + jump to selected link |
| Student resume | `App.tsx` / `StudentApp` | Read `session_id` from query when `student=1`; call existing `onResume` |
| Effectiveness UI | `EffectivenessDashboard.tsx` (+ optional small ComparisonCard) | Before/after cards using effectiveness payload |
| Dashboard detail | `DashboardDetail.tsx` | Fetch structured summary for teacher/parent and render above effectiveness |

### Student deep link (decision A)

- Query: `?student=1&session_id=<sid>` (matches current `create_demo_session` links — **not** `session=`)
- Behavior: on StudentApp entry, if `session_id` present, `onResume(session_id)` once; do not create a second session
- Teacher/parent links remain the existing `?login=1&role=...&student_id=<sid>` pattern

## Data model / fields (approved §2)

### TeacherSummary

| Field | Type | Source |
| --- | --- | --- |
| `class_name` | str | `"demo_class_5a"` or metadata / bind default for demo; else `"当前班级"` |
| `student_count` | int | `demo_class_data.class_size` or `1` |
| `avg_mastery` | float | `demo_class_data.avg_mastery` or session diagnosis avg |
| `top_weaknesses` | `[{skill, affected_students}]` | `common_weaknesses` + estimate (`ceil(student_count * 0.3)` or fixture counts if present) |
| `need_intervention_students` | `[{name, weakness, session_id}]` | Current demo child + optional 1–2 synthetic peers **only when** `metadata.demo_unit` set |
| `auto_graded_rate` | float | from `compute_metrics` |
| `estimated_time_saved_minutes` | float | `traditional - ilearn` from metrics |
| `narrative` | str | existing string `generate_audience_summary(..., audience="teacher")` or enrichment `teacher_summary` |

### ParentSummary

| Field | Type | Source |
| --- | --- | --- |
| `child_name` | str | profile nickname / metadata |
| `current_mastery` | float 0–1 | post score/100 if available else pre/100 |
| `mastery_change` | float | `demo_mastery_gain/100` or `(post-pre)/100` |
| `weak_skills` | list[str] | enrichment / diagnosis weak (parent-friendly ids or labels) |
| `learning_phase` | str | session phase value |
| `daily_practice_tips` | list[str] | split enrichment `parent_summary` / string generator into bullets |
| `next_milestone` | str | plan goal or first plan day title; fallback fixed Chinese line |
| `narrative` | str | full parent-facing string summary |

### Seed tweak

After grades exist:

```text
pre = 100 * correct / max(len(grades), 1)
post = clamp(pre + float(demo_mastery_gain), 0, 100)
metadata["post_assessment_score"] = post
```

`compute_metrics` already prefers `post_assessment_score` when set; ComparisonCards use pre/post + gain + weakness counts + grading times + confidence/evidence.

## Data flow / errors / tests (approved §2)

### Data flow

1. Landing selects role → `POST /demo/units/math_5_1/session` → `location = links[role]`
2. Student: query `session_id` → resume existing plan-phase session
3. Teacher/parent: existing dashboard deep link → `DashboardDetail` loads `GET /sessions/{id}/summary/{role}` → structured cards → Effectiveness ComparisonCards
4. Effectiveness GET unchanged; UI reads pre/post once seed writes post score

### Errors

| Case | Behavior |
| --- | --- |
| Unknown session | 404 |
| Non-demo session | Still 200; `student_count=1`; no synthetic peers; class fields degraded gracefully |
| Missing diagnosis/plan | Summaries still return with empty/weak defaults; do not 500 |

| Frontend | Landing role toggle uses correct link key; StudentApp resumes from `session_id`; Effectiveness ComparisonCards render with mocked metrics |
