# ILearn 商业化上线设计规格（今晚交付）

**日期：** 2026-09-14  
**决策人：** Agent（用户授权完全自行决策）  
**选定路径：** **软上线（A）+ 路演/获客包（C）** — 不做一晚内的完整收款（B）与准生产多租户 SaaS（D）

---

## 0. 初衷锚点（不可偏离）

ILearn 的初衷不是「搜题器」或「直接给答案的作业助手」，而是：

> **课标在环 · 多 Agent 协同 · 自适应个性化**  
> 让每个孩子拥有**课标对齐、数据驱动、持续进化**的 AI 学习伙伴。

产品承诺必须始终包含：

| 承诺 | 含义 | 商业化时禁止的异化 |
| --- | --- | --- |
| 课标在环 | 建议/组卷可追溯到课标条目与例题来源 | 纯 LLM 自由发挥、无 citation |
| 批改可审计 | OCR 与判分分离，`GradingReceipt` 可复现 | 黑盒「判对就算」 |
| 掌握度严谨 | practice / probe 双轨 + 证据日志 | 把「提示后做对」当成已掌握 |
| 辅导不泄题 | 苏格拉底 + Guard | 变成 Photomath/Gauth 式直接出答案 |
| 报告可带走 | 复盘 PDF / 学习报告 PDF | 只聊天、无沉淀 |
| 试点诚实 | 小学数学 4–6 · 北京·人教 | 假装全科全学段已商用成熟 |

**今晚一切迭代都必须能回答：**「这是否让孩子更被课标对齐地理解，或让家长/教师更能据此行动？」

## 1. 路径选择（已定案）

### 方案对比

| 方案 | 内容 | 一晚可行性 | 风险 | 结论 |
| --- | --- | --- | --- | --- |
| **A+C（选定）** | 公网可演示 + 转化落地页 + 候补名单 + Demo/竞品材料 + 核心闭环可信 | 高 | 无即时 ARPU | **最优** |
| B 可收费 MVP | A + 登录 + 支付 + 配额 | 中低 | 支付合规、退款、密钥、客服 | 推到下一周 |
| D 准生产 SaaS | B + 多租户 + 权限 + 监控合规全套 | 极低 | 范围爆炸、质量崩 | 拒绝 |

### 为何 A+C

1. 产品技术骨架已强（多 Agent、课标、证据、Tutor Guard、PDF、demo unit），缺口在**体验可信与商业叙事**，不在再堆 Agent。
2. 一晚内支付/多租户无法做完且易破坏初衷（泄题式「效果」营销）。
3. 软上线可立刻验证：家长是否愿留资、教师是否愿看演示、学生闭环是否「敢给孩子用」。
4. 已有公网隧道线索（`doc/ilearn_public_url.txt`）与 demo 单元/视频脚本资产，可复用。

### 今晚成功标准（Definition of Done）

1. **公网**：稳定 URL 可打开 Landing → 三角色演示（学生/家长/教师）至少一条完整路径。
2. **转化**：落地页有清晰价值主张 + 候补/预约留资（邮箱或表单落盘）。
3. **可信**：学生测评计时公平、离线/降级可跑、错误友好、隐私页可见。
4. **可带走**：报告/PDF 或家长一分钟行动摘要可用。
5. **叙事**：竞品对比一页 + 12 轮迭代记录 + Demo 脚本可对投资人/学校讲解。
6. **初衷**：任何对外文案不得承诺「秒出答案 / 代写作业 / 全科已覆盖」。

**明确不在今晚范围：** 微信/Stripe 正式收款、真实学校多租户、全学科扩展、儿童账号合规全量认证、Enhanced Flag 全面默认开启。

## 2. 竞品调研（12 家）与可借鉴优点

> 对比维度：定位、核心优点、与 ILearn 关系、今晚可偷师的点（不抄功能堆叠）。

| # | 竞品 | 定位 | 核心优点（应学习） | 对 ILearn 的启示 |
| --- | --- | --- | --- | --- |
| 1 | **松鼠 AI** | 自适应学习中心 + 知识点粒度诊断 | 知识点拆得极细；路径实时调整；家长可见指标 | 强化「薄弱点粒度 + 路径可见」叙事；勿夸大覆盖城市 |
| 2 | **科大讯飞学习机** | 硬件入口 + AI 1 对 1 精准学 | 区域考情/校内同步；启发式答疑；资源密度 | 试点诚实标注地区课标；手写/语音可后置，先做好文本可信 |
| 3 | **小猿 AI 学习机** | 诊–学–练–测 + 掌握度模型 | 「效果可见」产品叙事；掌握度作为北极星 | Landing/报告统一用「掌握度进步」而非「题量」 |
| 4 | **学而思 / 好未来（小精龙等）** | 学生 Agent + 学习机闭环 | 长期陪伴 Agent；诊–错–计划打通 | 会话可 resume；计划页下一挑战要醒目 |
| 5 | **作业帮** | 搜题 + 批改 + 错题本 | 入口极低；错题沉淀 | 错题来源追溯已有 → 强化「可审计」差异，避免沦为搜题 |
| 6 | **洋葱学园** | 动画课 + AI 私教 | 先概念再解题；低龄认知负荷控制 | 移动端单题聚焦；微课入口留给 hint 用尽后的柔性出口 |
| 7 | **Khanmigo** | 苏格拉底辅导 + 内容库绑定 | **不直接给答案**；教师工具；安全伦理叙事 | 这是 ILearn 最近的价值同盟 — 对外主打 Guard + 课标 citation |
| 8 | **Photomath** | 拍照分步解 | 步骤可视化极强；多解法 | 借鉴步骤展示，**禁止**默认直接终答；几何/可视化可渐进 |
| 9 | **Gauth** | 拍照 + 多科对话 | 追问体验流畅；转化漏斗短 | Landing CTA 要 ≤2 步进演示；对话要有护栏 |
| 10 | **豆包爱学** | 高频 App 内嵌学伴 | 分发优势；低摩擦入口 | 今晚用深链 `session_id` + 一键 demo，不自建流量池 |
| 11 | **Century Tech / 类 Knewton** | 学情引擎 B2B | 教师决策层； intervening 推荐 | 教师端要有「下一步动作」而非只热力展示 |
| 12 | **OpenMAIC / DeepTutor（开源同行）** | Agent 教学 / 辅导研究 | 模块化 Agent；可审计编排 | 保持 MultiAgentOrchestrator 可观测；开源叙事作信任背书 |

### ILearn 差异化定位（对外一句话）

**「课标可追溯的多 Agent 诊断—规划引擎：辅导不泄题，掌握度有证据，报告可带走。」**

相对搜题类（作业帮/Photomath/Gauth）：我们卖的是**学习闭环与证据**，不是答案。  
相对硬件巨头（讯飞/小猿/学而思）：我们卖的是**可审计编排 + 开源可验证 + 轻部署试点**，不是全科资源库。  
相对 Khanmigo：我们更强调**中国课标在环与批改收据**，试点小学数学可立即跑通。

## 3. 产品架构（今晚增量）

```text
[Landing 商业页]
  ├─ 价值主张 / 初衷 / 竞品差异一句话
  ├─ 一键 Demo（学生|家长|教师）
  ├─ 候补留资 → POST /waitlist → data/waitlist.jsonl
  └─ 隐私 · 理念 · 能力边界

[现有 FastAPI + React 向导]  ← 不重写核心
  ├─ 学生：公平计时测评 → 批改 → 诊断 → 计划 → PDF
  ├─ 家长：一分钟行动摘要（可读）
  └─ 教师：demo 面板 + 分层建议（最小可用）

[生产粘合]
  healthz · 静态托管 dist · 限流 · 友好错误 · 公网隧道/托管
```

**原则：** 增量旁路，不拆 MultiAgent 主链路；Enhanced Flag 保持默认关（避免未验证旁路进生产）。

## 4. 商业模型（今晚只铺管道）

| 阶段 | 模式 | 今晚动作 |
| --- | --- | --- |
| 获客 | 免费完整教学单元演示 + 候补 | Waitlist + Demo CTA |
| 验证 | 家庭试点 / 教师试用 | 收集邮箱 + 角色意图 |
| 下周 | Freemium：每月 N 次诊断会话 | 文档中写清，不实现支付 |
| 远期 | 学校 Pilot License | 路演材料预留 B2B 页 |

定价文案可写「即将开放早鸟席位」，**不写死价格数字**（避免未备案承诺）。

## 5. 风险与护栏

| 风险 | 缓解 |
| --- | --- |
| 被当成搜题工具 | 文案 + Tutor Guard + 公开「不直接给终答」 |
| 公网隧道不稳定 | 双轨：cpolar/cloudflared + 本地 fallback 说明 |
| LLM 费用/失败 | 默认可离线演示；有 Key 则升级 |
| 儿童隐私 | 隐私页；演示账号；不收集真实身份证 |
| 范围膨胀 | 本规格 §1 成功标准为唯一验收 |
