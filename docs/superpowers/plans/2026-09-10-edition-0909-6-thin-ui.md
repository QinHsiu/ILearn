# Edition 0909_6 Thin Enhanced UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a flag-gated Enhanced student panel (SVG radar + weak concepts + emotion) on teacher/parent `DashboardDetail` and student `StudentSummaryPanel`, fed by existing `?enhanced=true` summary APIs.

**Architecture:** Port `doc/chart.txt` into `frontend/src/components/Enhanced/*` with CSS modules (`enhanced.module.css`), `VITE_ENHANCED_UI` gate, and `api/client` summary calls that parse `enhanced_profile`. No new backend routes, no echarts, no Tailwind.

**Tech Stack:** React 19, Vite, Vitest, Testing Library, existing `frontend/src/api/client.ts`. Coding draft: `doc/chart.txt`. Spec: `docs/superpowers/specs/2026-09-10-edition-0909-6-thin-ui-design.md`.

## Global Constraints

- `VITE_ENHANCED_UI` default false → `ENHANCED_UI_ENABLED` in `frontend/src/config/enhanced.ts`
- Consume **`enhanced_profile`** from summary payloads (never invent `data.profile`)
- Use **`sessionId`** with existing endpoints: `/sessions/{id}/summary/{teacher|parent|student}?enhanced=true`
- **Parent endpoint exists** (`getParentSummary` / app.py `summary/parent`) — use it for `surface === 'parent'`; do **not** fall back to teacher unless a runtime 404 is discovered in verification
- Adult dashboards (`teacher` / `parent`): weak-concept copy「薄弱知识点」(`viewMode="teacher"`)
- Student:「待加强」(`viewMode="student"`)
- Styles: single `enhanced.module.css` only (no global Enhanced CSS, no Tailwind)
- Radar labels: truncate Chinese names to **6 characters** + ellipsis; full name in SVG `<title>`
- Loading: while UI flag on and fetch in flight, show minimal「加载画像…」placeholder
- Flag off / missing profile / API error → `null` (no blocking error UI)
- Mastery keys &lt; 3 → radar downgrade text (from chart.txt)
- Prefer `api` client over raw `fetch` for base URL / consistency
- Do not add echarts; do not implement path/roles/reflection/trend
- PowerShell: no `&&`, no bash heredocs for commits
- Commit only frontend-related files for this feature
