```python
def get_session(self, session_id: str) -> SessionState:
    return self._store.load(session_id)

def heartbeat(self, session_id: str) -> dict:
    from ilearn.core.datetime_utils import utc_now
    session = self._store.load(session_id)
    session.metadata["last_heartbeat"] = utc_now().isoformat()
    self._store.save(session)
    return {
        "ok": True,
        "phase": session.phase.value if hasattr(session.phase, "value") else str(session.phase),
        "server_time": utc_now().isoformat(),
    }
```

**Interfaces:**
- Consumes: Task 2 endpoints; existing `SessionState` type; `api` object
- Produces:
  - `api.getSession(sessionId: string): Promise<SessionState>`
  - `api.heartbeat(sessionId: string): Promise<{ ok: boolean; phase: string; server_time: string }>`
  - `useSessionSync({ sessionId, onSync, hasUnsavedChanges }): { isSynced: boolean; lastSync: number; forceSync: () => Promise<boolean> }`

Hook behavior (exact):
1. If `!sessionId`, do not start interval / listeners that call API.
2. `visibilitychange` when `document.visibilityState === 'visible'` → `getSession` → `onSync`.
3. `setInterval` 30000ms → `heartbeat`; on failure set `isSynced` false.
4. `beforeunload` preventDefault when `hasUnsavedChanges()` true.

`StudentApp`:
- Keep a `session` state or derive; on sync apply paper/answers/step like `onResume` core (no report required).
- `hasUnsavedChanges`: true if any answer text differs from last synced answers **or** simplest MVP: `Object.keys(answers).length > 0 && step === 1` before submit — prefer: compare to `lastSyncedAnswersRef`.
- Call `useSessionSync({ sessionId, onSync, hasUnsavedChanges })` inside `StudentApp`.

describe('useSessionSync', () => {
