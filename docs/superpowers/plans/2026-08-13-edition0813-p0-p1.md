# edition_0813 P0+P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement edition_0813 P0 (profile/themes + citations) and P1 (four validators + situational interest / learning_difficulty) by extending the existing ILearn Agent pipeline.

**Architecture:** Schema-first increments on `StudentProfile` / `AssessmentItem` / portrait; CSS theme packs in Streamlit; example bank + `source_refs` binding in AssessmentAgent; rule-based validators after paper build inside `MultiAgentOrchestrator.generate_assessment`; interest signals into portrait and blueprint fill.

**Tech Stack:** Python 3.11+, Pydantic, FastAPI, Streamlit, pytest

**Spec:** `docs/superpowers/specs/2026-08-13-edition0813-p0-p1-design.md`

## Global Constraints

- Approach A only: no `ilearn/edition0813/` parallel package
- Keep `curriculum_objective_ids` working; add `source_refs` alongside
- Validators are rule-based MVP (no LLM calls)
- Do not implement P2/P3 (WCAG Eval, ParetoGrad, PyraMathBench, Math-Verify)
- Prefer TDD: failing test → implement → pass → next task
- `doc/` and `docs/` are gitignored; commit code/tests/VERSION/README only when user asks
