### Task 2: Structured `TeacherSummary` / `ParentSummary` builders

**Files:**
- Modify: `ilearn/core/audience_summary.py`
- Create: `tests/test_audience_summary_structured.py`

**Interfaces:**
- Consumes: `SessionState`, `compute_metrics(session)` from `ilearn.core.effectiveness`, existing `generate_audience_summary`
- Produces:

```python
class WeaknessStat(BaseModel):
    skill: str
    affected_students: int

class InterventionStudent(BaseModel):
    name: str
    weakness: str
    session_id: str

class TeacherSummary(BaseModel):
    class_name: str
    student_count: int
    avg_mastery: float
    top_weaknesses: list[WeaknessStat]
    need_intervention_students: list[InterventionStudent]
    auto_graded_rate: float
    estimated_time_saved_minutes: float
    narrative: str

class ParentSummary(BaseModel):
    child_name: str
    current_mastery: float  # 0..1
    mastery_change: float   # fraction, e.g. 0.18
    weak_skills: list[str]
    learning_phase: str
    daily_practice_tips: list[str]
    next_milestone: str
    narrative: str

def build_teacher_summary(session: SessionState) -> TeacherSummary: ...
def build_parent_summary(session: SessionState) -> ParentSummary: ...
```

**Builder rules (lock these):**
- `demo = bool(session.metadata.get("demo_unit"))`
- `class_data = session.metadata.get("demo_class_data") or {}`
- Teacher: `class_name = "demo_class_5a" if demo else "当前班级"`; `student_count = int(class_data.get("class_size") or 1)`; `avg_mastery = float(class_data.get("avg_mastery") or 0.0)` when class_data else mean of diagnosis `score_rate` (or `0.0` if none)
- `top_weaknesses`: for each string in `class_data.get("common_weaknesses") or []`, `affected_students = max(1, ceil(student_count * 0.3))`; if empty, use first 3 weak diagnosis knowledge names/ids with `affected_students=1`
- `need_intervention_students`: always include current child (`nickname` or `"学生"`, first weakness skill, `session.session_id`); if `demo`, append up to 2 synthetic peers `{"name": "小红", ...}`, `{"name": "小刚", ...}` with distinct weaknesses from `top_weaknesses` (reuse first skill if needed)
- `auto_graded_rate = metrics.auto_graded_count / max(metrics.total_questions, 1)`
- `estimated_time_saved_minutes = metrics.traditional_grading_time_minutes - metrics.estimated_grading_time_minutes`
- `narrative`: prefer `enrichment["teacher_summary"]` if str non-empty else `generate_audience_summary(..., audience="teacher")`
- Parent: `child_name` from profile nickname or `"孩子"`; `current_mastery = (post or pre) / 100.0`; `mastery_change = metrics.mastery_gain / 100.0`
- `weak_skills` from enrichment `weak_skills` or diagnosis weak ids (max 5)
- `learning_phase = session.phase.value` if enum else `str(session.phase)`
- `daily_practice_tips`: split `parent_summary` enrichment / narrative on newlines / `•` bullets; drop empties; if none, call `generate_audience_summary(..., audience="parent")` and split
- `next_milestone`: `session.plan.goal` if present else `"完成本单元薄弱点巩固"`
- `narrative`: enrichment `parent_summary` or generated parent string

```typescript
// demoSessionQuery.ts
export function readDemoSessionId(search: string): string | null {
  const raw = new URLSearchParams(search.startsWith('?') ? search : `?${search}`).get('session_id')
  const id = (raw || '').trim()
  return id || null
}
```

In `StudentApp`, after `onResume` is defined:

```tsx
const resumedFromQueryRef = useRef(false)
useEffect(() => {
  if (resumedFromQueryRef.current) return
  const id = readDemoSessionId(window.location.search)
  if (!id) return
  resumedFromQueryRef.current = true
  setBusy(true)
  void onResume(id)
    .catch((err) => setError(err instanceof Error ? err.message : String(err)))
    .finally(() => setBusy(false))
}, [])
```
