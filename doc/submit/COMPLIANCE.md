## 1. 数据类型

| 类别 | 说明 |
|------|------|
| 诊断 / 练习题 | 小学数学（四至六年级）诊断题、练习卷（试点以北京·人教为主） |
| 课标与知识结构 | 人教版课程标准映射、知识点图谱与别名 |
| 演示画像 | 模拟学生 / 班级数据（化名：小明、小红等） |
| 运行会话 | 本地会话级 JSON（测评、批改、诊断、计划临时存储） |

---

## 2. 数据来源与授权状态

| 数据类型 | 来源 | 授权状态 |
|----------|------|----------|
| 人教版课标要点 | 公开教育标准 / 课标文本整理 | 公开数据，非商业学术演示 |
| 数学题库 | 公开题库 + 项目自制 / 导入脚本清洗 | 非商业使用 |
| 学生画像与班级指标 | 演示单元模拟生成（如 `math_5_1`） | 无真实个人数据 |
| 知识图谱与 KP 别名 | 课标映射 + 内部构建 | 项目内部资产 |
| 效果量化演示值 | 演示单元预置 / 规则估算（带 `is_simulated` 标识） | 明示模拟，不冒充真实实验结论 |

---

## 3. 脱敏与隐私保护

1. **演示数据全部为模拟生成**，使用化名，不对应真实学生。  
2. **不收集、不存储任何真实个人信息**（姓名、手机号、学校学号、人脸等）。  
3. **会话数据本地临时存储**（`data/sessions/`），用于功能演示与开发调试；提交包可清空演示会话。  
4. **无第三方数据共享**；默认不向外部上传学生作答内容。  
5. **家长端输出强制清洗内部 ID**（如 `kp_*`）与技术黑话，降低误读与二次传播风险。

---

## 4. 行业风险提示与人工确认边界

1. **AI 诊断结果仅供参考，不替代教师专业判断。**  
2. **学习计划为算法建议**，应经教师审核后执行。  
3. **模型 / 规则输出可能存在偏差**，重要干预决策建议人工复核。  
4. **不自动向家长或外部渠道推送诊断结论**；展示限于授权角色的仪表盘 / 导出。  
5. **效果面板若为演示估算**，界面标注「模拟数据」及数据来源说明。

---

## 5. 合规声明

本项目演示与开源发布符合《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》的基本要求：

- 处理目的限于教育 AI 研究、竞赛演示与开源协作；  
- 不涉及真实未成年人个人信息的大规模采集；  
- 数据处理默认在本地完成，不涉及数据出境；  
- 对模拟数据与真实数据边界在文档与 UI 中予以区分说明。

如竞赛组织方另有数据备案或授权模板要求，可使用同目录下的《授权确认书》模板补充签署。
