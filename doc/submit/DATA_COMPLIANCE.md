# ILearn 数据来源与合规说明

> 项目：ILearn（课标在环 · 多 Agent 协同 · 自适应学习引擎）  
> 赛事：2026 世界人工智能开源大赛（GOAI 2026）｜赛道二 AI+教育  
> 仓库：https://github.com/QinHsiu/ILearn  
> 更新日期：2026-09-06

---

## 1. 数据类型

| 数据类型 | 具体内容 | 用途 |
|----------|----------|------|
| 课标数据 | 人教版小学数学课程标准（四至六年级） | 知识图谱构建、CurriculumAgent 检索 |
| 题目数据 | 小学数学诊断题、练习卷（选择题/填空题/解答题） | AssessmentAgent 组卷、PracticeAgent 练习 |
| 学生画像 | 模拟学生数据（化名、年龄、掌握度） | 演示模式、效果量化展示 |
| 知识图谱 | 知识点层级关系、前后置依赖 | DiagnosisAgent 诊断、PlanningAgent 规划 |

---

## 2. 数据来源

| 数据类型 | 来源 | 说明 |
|----------|------|------|
| 人教版课标 | 中华人民共和国教育部《义务教育数学课程标准》 | 公开教育标准文档 |
| 数学题库 | 公开题库资源 + 团队自制 | 非商业用途，仅用于学术研究 |
| 学生画像 | 模拟生成（非真实数据） | 全部为化名，不涉及任何真实个人信息 |
| 知识图谱 | 基于课标人工构建 + 团队自制 | 内部构建，不依赖第三方 |

---

## 3. 授权方式

| 数据 | 授权状态 | 授权说明 |
|------|----------|----------|
| 人教版课标 | 公开数据 | 国家公开的教育标准，可自由使用 |
| 公开题库 | 非商业授权 | 仅限学术研究与非商业用途 |
| 自制数据 | 自有版权 | 团队自制，拥有完整版权 |
| 模拟画像 | 自有版权 | 模拟生成，无隐私风险 |

开源协议：本项目采用 **MIT** 协议开源，代码可自由使用、修改、分发。

---

## 4. 处理方式

| 数据处理环节 | 方式 | 说明 |
|--------------|------|------|
| 数据采集 | 人工整理 + 程序化处理 | 从公开来源提取并结构化 |
| 数据存储 | 本地文件存储（JSON/CSV） | 无云端存储，无第三方共享 |
| 数据脱敏 | 模拟数据替代真实数据 | 学生画像全部为化名 |
| 数据处理 | 本地计算（CPU） | 不涉及数据出境 |
| 数据清理 | 会话结束后自动清理 | 无持久化存储用户数据 |

---

## 5. 隐私保护

| 保护措施 | 实施方式 |
|----------|----------|
| 不收集真实个人信息 | 演示数据全部为模拟生成 |
| 无用户注册/登录 | 演示模式无需任何个人信息 |
| 无数据持久化 | 会话数据临时存储，结束后自动清理 |
| 无第三方共享 | 所有数据本地处理，不上传任何平台 |
| 无 Cookie/跟踪 | 前端不设置任何追踪 Cookie |

---

## 6. 行业风险提示

| 风险类型 | 说明 | 缓解措施 |
|----------|------|----------|
| 诊断准确性 | AI 诊断结果可能存在偏差 | 标注「仅供参考，不替代教师专业判断」 |
| 学习路径建议 | 算法生成的学习计划可能不完美 | 需教师审核后执行 |
| 模型输出偏差 | LLM 可能产生不准确输出 | 离线规则引擎作为降级方案 |
| 过度依赖 | 家长/学生可能过度依赖 AI 判断 | 明确标注「需人工确认」 |

---

## 7. 使用边界与人工确认

| 边界 | 说明 |
|------|------|
| 诊断结论 | 仅供参考，需教师最终确认 |
| 学习计划 | 算法建议，需教师审核调整 |
| 家长端报告 | 标注「请以教师意见为准」 |
| 不替代专业决策 | 项目不替代教师的教学判断 |

---

## 8. 合规声明

本项目符合《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》要求。所有数据处理均在本地完成，不涉及数据出境，不收集、不存储任何真实个人身份信息。演示数据均为模拟生成，不涉及任何真实学生信息。
