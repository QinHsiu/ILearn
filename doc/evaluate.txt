一、通用评估框架与基准
1. EduAgentBench
首个基于教育理论、面向真实教学场景的辅导Agent综合评估基准。包含150个质量管控任务，覆盖三个能力维度：

专业教学判断（Professional Pedagogical Judgment）

情境化多轮辅导（Situated Multi-turn Tutoring）

Canvas式教学工作流完成（Canvas-style Teaching Workflow Completion）

评估发现，当前前沿模型在有界教学判断方面表现尚可，但在自主教学工作流执行方面仍远未达到专业教学标准。

2. VeAgentBench
字节跳动推出的开源评估基准，覆盖教育、金融、法律、个人助理四大真实场景，首批公开145道任务。评估Agent的四个核心维度：

工具调用：能否正确选择并调用外部工具

知识检索（RAG） ：能否从文档中精准提取信息

记忆管理：能否记住并利用用户历史信息

链式任务执行：能否完成多步骤的复杂任务

配套的veADK开发框架支持一键集成大模型、工具调用、RAG与记忆管理。

3. ELMES
华东师范大学开发的开源自动化评估框架，专门用于评估LLM在教育场景中的表现。覆盖四个关键教育场景：

知识点讲解

引导式问题解决教学

跨学科教案生成

情境化问题生成

采用混合评估引擎，通过LLM-as-a-Judge方法量化传统上主观的教学指标。代码已开源：https://github.com/sii-research/elmes.git[reference:10]

4. KGCE
华中师范大学提出的知识增强双图评估器，支持跨平台（Windows、Android）教育Agent评估。构建了104个教育相关任务的数据集，采用双图评估框架将任务分解为多个子目标并逐项验证完成状态，提供细粒度评估指标。代码：https://github.com/Kinginlife/KGCE[reference:13]

5. AgentOS OpenLab
滴普科技联合南方科技大学、北京邮电大学等高校共建的智能体评测开放实验室，围绕智能体执行全过程构建评测闭环。覆盖执行轨迹记录、关键检查点切分、评测规则生成、测试执行、评分报告输出等环节。

二、按Agent类型的针对性评估方案
1. 个性化学习规划 Agent
TutorBench：以学生为中心的基准测试，基于真实学习者画像和一视角交互协议，从学习者视角衡量自适应辅导能力。

LEA框架：采用多智能体编排，根据学习者表现、认知负荷评估、最近发展区推理和动机追踪动态调整任务难度。评估框架包含模式特定的性能指标和模拟学习者Agent。

评估指标参考：

ROUGE-L、BERTScore（内容质量）

风格迁移率、专业度召回（个性化适配）

NLI-based忠实度

LLM-as-Judge的相关性与 groundedness 评分

2. 作业辅导 Agent
TutorGym：标准化的测试平台，将AI Agent置于已有智能辅导系统（如Cognitive Tutors）的交互界面中。在每一步问题解决中，AI Agent被问及作为导师或学习者会做什么：

作为导师：生成示例、提示、步骤级正确性反馈

作为学习者：从辅导中学习，其错误和学习轨迹可与真实学生数据对比

TutorGym包含223个不同的辅导领域。初期评估发现，当前LLM在辅导方面表现不佳——标记错误动作的正确率不高于随机水平，下一步动作的正确率仅约52-70%。

BEA 2025 Shared Task：专门评估AI辅导者的教学能力，聚焦于教育对话中学生错误纠正的场景。包含五个赛道：

错误识别

精确错误定位

提供指导

反馈可操作性

辅导者身份检测

最佳结果在教学能力评估赛道上的Macro F1分数为58.34-71.81（三分类问题），表明仍有显著提升空间。所有资源已公开：https://github.com/kaushal0494/UnifyingAITutorEvaluation[reference:27]

3. 学情诊断 Agent
苏格拉底教育系统（Socratic Education System） ：开源的多智能体K12教育平台，通过多智能体协作精准捕捉学生逻辑断裂点，为教师提供具有教育心理学背景的学情诊断与教学建议。包含Profiler Agent深度复盘学习历史、提取核心知识点并识别认知障碍。

WeSmartFlow：腾讯开源的Agent-native自适应学习框架，承担知识诊断、路径规划、个性化辅导、内容生成、测验反馈与长期记忆演化等核心能力。

学情诊断评估要点：

薄弱点识别的准确率和召回率

诊断报告与教师专家判断的一致性

改进建议的可操作性和优先级合理性

4. 教师备课 Agent
ELMES已覆盖跨学科教案生成的评估场景。

claude-education-skills：包含111项基于证据的教学技能的开源库，涵盖课程设计、教案规划和评估。

OpenMAIC：开源AI平台，通过多智能体编排将任何主题或文档转变为交互式课堂体验，支持一键生成课程、AI教师和同学实时互动。

清华多智能体AI课堂系统：开源系统，通过模拟真实教学场景中的师生互动，实现了从课件生成到作业批改的全流程自动化，并通过两年真实课堂数据验证了技术可行性。

备课评估指标：

教案与课程目标的对齐度

教学活动的多样性与适龄性

分层教学方案的差异化程度

与教师人工教案的质量对比（可由专家评分）

5. 阅读与语言学习 Agent
HSKBenchmark：首个用于汉语作为第二语言习得的分阶段建模与写作评估基准。配套HSKAgent是在语法数据集和1万篇学习者作文上微调的自动化评估器。代码：https://github.com/CharlesYang030/HSKB[reference:38]

BabelJudge：开源基准与可靠性审计框架，衡量LLM-as-a-Judge在多语言和Agent轨迹中的四种失败模式。Python包：https://github.com/Shreyaskc/BabelJudge[reference:40]

SEED（Scoring Educational Effectiveness of a Dialogue） ：专门评估LLM在语言学习对话游戏中回复的教学价值的新指标。

VerbaVista：开源AI Agent，专注于全球语言能力测试的评估。

语言学习评估指标：

词汇解释的准确性与适龄性

语法反馈的正确率和可理解性

表达优化的自然度提升

口语交互的流畅度和纠音准确率

6. 职业教育/编程教育 Agent
MathTutorBench：开源基准，用于评估LLM导师的开放式教学能力。研究发现：学科专业知识（解题能力）并不直接转化为良好的教学能力。

EduAgentQG：华东师范大学开源的多智能体协作系统，用于K12数学题目的自动生成与评估。采用BLEU、METEOR、ROUGE-L、BERTScore等指标。

编程教育评估指标：

代码辅导的引导有效性（学生能否自主修正）

项目任务拆解的合理性

模拟面试的覆盖度和反馈质量

学习路线建议与岗位技能匹配度

评估维度总结
无论评估哪类Agent，都应关注以下共性维度：

教学有效性：是否真正促进了学习，而非仅给出正确答案

适应性：能否根据学生差异动态调整

安全性：是否避免不当内容、不替代教师最终决策

可解释性：每一步判断是否可追溯、可理解

效率：响应速度、资源消耗

当前教育Agent评估的整体结论是：模型在知识性任务上表现尚可，但在真正的教学能力（诊断、引导、自适应）上仍有巨大差距——这恰恰说明建立系统化评估机制的必要性。
