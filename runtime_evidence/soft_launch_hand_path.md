# Soft-launch hand path checklist（不依赖录屏）

**日期：** 2026-09-15  
**范围：** 小学数学 4–6 · 北京·人教 · 不泄终答

## 学生（≤2 点击进证据）

1. Landing →「体验小数乘法」或角色卡学生入口  
2. 学情页可见：掌握证据四元组、绑定码、亲子题卡 Soft PDF  
3. 错题：概念分镜海报可见；苏格拉底仍不给终答  
4. 「开始错题重练」进入作答步（step 1）

## 家长

1. Landing 家长卡一键演示 / 登录页「一键体验」  
2. 零状态有绑定码说明；输入 6 位码可绑定  
3. 本周证据 + 今晚可做三件事 + 亲子题卡 CTA

## 教师

1. Landing 教师卡一键演示 → 选班见总览  
2. 干预名单：单人布置 / **一键干预名单批量** / 全班布置  
3. 班级布置回执（跨学生）列表更新  
4. 学情详情：题级课标预览（无终答）

## 门禁

- `pytest tests/eval_winbars -q`  
- Landing / 关键 vitest 冒烟（按需）
